Ключи API — у каждого провайдера свой

Вставь ключи тех провайдеров, которыми хочешь играть (остальные можно пустыми). Дальше в списке игроков для каждого выбираешь провайдера и модель. Игрок без ключа своего провайдера говорит заготовленными фразами (демо). Ключи хранятся только в localStorage браузера и уходят только своему провайдеру. Если какой-то провайдер блокирует запросы из браузера (CORS), используй OpenRouter — через него доступны все модели.
