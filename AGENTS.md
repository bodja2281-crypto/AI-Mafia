# AGENTS.md — контекст проекта для ИИ-помощников

Этот файл нужен, чтобы любая нейросеть (Claude, ChatGPT, Gemini, Cursor и т.д.) сразу поняла проект и продолжила работу без расспросов. Целиком отдай его модели вместе с вопросом или задачей.

## Что это

«AI Mafia»: веб-игра, в которой нейросети играют в «Мафию» друг с другом через API. Зритель смотрит и слушает. Статический front-end (HTML, CSS, vanilla JS), без бэкенда, сборки и зависимостей. Ключи API лежат в `localStorage` и уходят только своему провайдеру. Интерфейс и промпты на русском.

Вся работа ведётся в одном месте: репозиторий https://github.com/bodja2281-crypto/AI-Mafia, ветка `main`. Сайт на GitHub Pages обновляется из неё автоматически. Другие копии (например, MrPauk335/AI-Mafia) не трогай, пока владелец не попросит.

## Файлы

| Файл | Что внутри |

Скрипты подключаются как обычные `<script>`: сначала `avatars.js`, потом `app.js`. Глобальные имена из `avatars.js` доступны в `app.js`.

## Как запускать и проверять

```bash
npx http-server -p 8080 -c-1
```

Сборки и тестов нет. Проверка: открыть страницу, нажать «Начать игру». Без ключей игра идёт в демо-режиме с заготовленными фразами, так что интерфейс можно проверять без API. Логику запросов проверяли, подменяя `window.fetch` в консоли браузера. Реальные API при разработке не вызывались, поэтому названия моделей и CORS у части провайдеров не проверены.

## Архитектура `app.js`

**Настройки.** `DEFAULTS`, `loadSettings()` (с миграцией старых форматов), `saveSettings()`. Ключи: `S.keys[providerId]`, отдельно `S.elevenKey`. `S.avatarMode`: `ball` (по умолчанию), `art`, `logo`, `off`. Игроки: `S.players[]` с полями `name` (пусто = авто по бренду), `provider`, `model`, `voiceO`/`voiceB`/`voiceG` (голоса OpenAI, браузера, Gemini), `persona`.

**Провайдеры.** `PROVIDERS` с полями `kind` (`openai` или `anthropic`), `base`, `def`, `models`. Все, кроме Anthropic, ходят на OpenAI-совместимый `/chat/completions`: OpenAI, Gemini (`.../v1beta/openai`), DeepSeek, xAI, Deploy, OpenRouter, свой адрес. Anthropic использует Messages API с заголовком `anthropic-dangerous-direct-browser-access`.

**Запросы.** `buildRequest(p, system, user, maxTokens)` собирает запрос под провайдера, `llm()` отправляет его с таймаутом 60 с, повторами и ожиданием при 429. Для экономии выключаются рассуждения: `reasoning_effort` ставится только там, где модель его принимает; DeepSeek reasoner подменяется на `deepseek-chat`. Если модель отвечает 400 из-за этого параметра, запрос повторяется без него, а модель запоминается в `NO_REASONING`.

**Озвучка.** `ttsPrepare` заранее грузит аудио (OpenAI `/audio/speech`, ElevenLabs, Gemini TTS через `generateContent` с конвертацией PCM в WAV, либо браузерный `SpeechSynthesis`). `prepTurn` получает текст от модели, кладёт его в общий лог и запускает загрузку аудио. `runTurns` готовит следующую реплику, пока играет текущая. `say()` показывает облачко и играет звук одновременно.

**Ход игры.** `runGame` → `setupGame` (роли и личности через `buildIdentities`) → `introPhase` (знакомство) → цикл `nightPhase` (мафия, доктор, комиссар через `nightAct`, всё вслух) → `dayPhase` (`runTurns` + `voting`) до `winner()`. Паузу и остановку обеспечивает `gate()`: он бросает `'stop'`, если `G.token !== runToken`.

**Личности.** `buildIdentities`: имя = название бренда, дубликаты получают номера («ChatGPT 1/2»), голоса не повторяются в рамках движка озвучки (`voiceManual` отключает автоподбор).

**Сцена.** `renderTable` создаёт `.seat`, `layoutSeats` раскладывает их в два ряда вокруг стола и задаёт размер `--ball`. Реплика с именем говорящего находится в центре стола; длинный текст прокручивается внутри `#speechText`. `renderTableStats` обновляет число живых игроков и режим (AI / демо). Журнал вынесен справа, на узких экранах — под столом. Табло обновляют `setPhase` и `setCenter` через `renderBanner`. Состояния игрока — CSS-классы на `.seat`: `speaking`, `thinking`, `dead`, `target`.

## Правила секретности ролей (не ломать)

- Мирные не знают ролей других игроков.
- Мафия знает своих и слышит свои ночные разговоры.
- Комиссар знает только результаты своих проверок.
- Публичный лог (`publicLog`, последние 30 реплик) не содержит ночной речи.
- Зритель видит и слышит всё.

## Договорённости

- Язык интерфейса, комментариев и промптов: русский. Идентификаторы в коде: английские.
- Без фреймворков, сборщиков и внешних зависимостей. Один `app.js`, один `style.css`.
- Ключи и секреты не коммитить и не выводить в чат.
- Любая ошибка API показывается в чате стола строкой с `⚠` (провайдер и модель в тексте).
- Все ИИ-помощники и люди работают в одной ветке `main` одного репозитория, без отдельных веток и форков. Коммить небольшими порциями. Перед каждым пушем: `git pull --rebase origin main` (или `git fetch` и слияние), потом `git push`. Никогда не перезаписывай чужие коммиты (`--force` запрещён). Перед правкой файла посмотри свежий `git log`, чтобы не делать то, что уже сделал другой.

## Типичные грабли

- Параметр `reasoning_effort` ломает не все модели. Не добавляй его без проверки и не убирай откат при 400.
- Спрайт-аватарки позиционируются через CSS-переменные `--nx/--ny/--s`; шарики рисуются SVG и от них не зависят.
- Центральная реплика ограничена по высоте, прокрутка висит на `#speechText`; не увеличивай её поверх рядов игроков.
- Мимика шарика: закрытый рот `.m-closed` и открытый `.m-open` управляются CSS-переменной `--mo` (0..1), которую `mouthTick` в `app.js` ставит по громкости аудио (Web Audio `AnalyserNode`) или процедурно для браузерного голоса и демо. Взгляд: `--lx/--ly` (`lookAt`), моргание: класс `.blink`. Эмоции завязаны на классы `.seat` (`thinking`, `target`, `dead`, `body.night`).
- Старые настройки пользователя мигрируют при загрузке: если ничего не мигрировало, смотри `loadSettings`.
